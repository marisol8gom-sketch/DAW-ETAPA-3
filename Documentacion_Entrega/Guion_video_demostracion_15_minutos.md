# Guion para el video de demostración (máximo 15 minutos)

**Proyecto:** Sistema de control de inventario y ventas — Almacenes Mega Oferta  
**Duración sugerida:** 8–12 minutos  
**Enlace del video:** Pegar aquí el enlace real después de subir la grabación (YouTube no listado, OneDrive o Google Drive con permisos de visualización).

> Este archivo es una guía de grabación, no sustituye el video solicitado. Deben grabar la pantalla con el sistema ejecutándose y compartir el enlace real.

## Guion por tiempos

| Tiempo | Qué mostrar | Qué explicar |
|---|---|---|
| 0:00–0:45 | Portada o página principal | Presentar el sistema, objetivo y equipo. |
| 0:45–1:45 | Inicio de sesión | Explicar el acceso de administrador y el registro de cliente. No mostrar contraseñas personales. |
| 1:45–3:00 | Catálogo, búsqueda y carrito | Mostrar cómo se consulta un producto, se agrega al carrito y se inicia un pedido. |
| 3:00–4:30 | Panel administrativo | Explicar los indicadores principales y la navegación del panel. |
| 4:30–6:00 | Gráficas de Chart.js | Mostrar las gráficas de inventario por categoría y pedidos por estado. Explicar qué información comunica cada una. |
| 6:00–7:15 | SweetAlert2 | Mostrar una confirmación y un mensaje de resultado. Si se prueba una eliminación, usar un registro de prueba. |
| 7:15–8:45 | Validaciones | Intentar enviar campos vacíos, un correo inválido, contraseñas que no coinciden y valores inválidos de precio/stock. Mostrar los mensajes. |
| 8:45–10:15 | Reportes | Mostrar el resumen, la tabla por categoría y exportar inventario y pedidos a CSV. Abrir uno de los archivos descargados. |
| 10:15–11:00 | Investigación PDF | Mostrar el PDF y mencionar que documenta Chart.js, SweetAlert2, validación y exportación CSV. |
| 11:00–11:45 | Cierre | Resumir los aportes y mostrar el repositorio de GitHub. |
