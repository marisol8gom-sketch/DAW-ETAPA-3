# Entrega final — Etapa 3, Avance 1

## Contenido
- `Proyecto_Almacenes_Mega_Oferta/`: código fuente principal del sistema.
- `Proyecto_Almacenes_Mega_Oferta/Investigacion_Librerias_JS_APA7.pdf`: investigación sobre las librerías JavaScript aplicadas.
- `Guion_video_demostracion_15_minutos.md`: guion y lista de verificación para grabar el video.
- Este archivo: instrucciones finales.

## Requisitos cubiertos en los archivos
- Gráficas de Chart.js en el panel administrativo (verificar en navegador).
- Diálogos con SweetAlert2 (verificar en navegador).
- Módulo adicional de reportes con resumen y exportación CSV.
- Validaciones de formularios descritas en el README y el informe (probar cada formulario).
- PDF de investigación con referencias web en estilo APA 7.

- API externa de tipo de cambio (`js/api.js`, ver `Documentacion_Entrega/API_EXTERNA.md`).

## Pendientes que requieren una acción real del equipo
1. **Video:** grabar la pantalla con el sistema funcionando, subirlo y sustituir el campo del guion por la URL real. No se puede generar una grabación auténtica sin ejecutar y grabar la demostración.
2. **GitHub:** abrir el repositorio remoto, comprobar que la versión entregada esté publicada y hacer commit/push de los archivos nuevos. El archivo ZIP no publica cambios por sí solo.
3. **Pruebas:** ejecutar el sistema y confirmar los resultados en navegador. La revisión estática del código no equivale a una prueba funcional completa.

## Ejecución rápida
1. Extraer el ZIP.
2. Abrir la carpeta `Proyecto_Almacenes_Mega_Oferta`.
3. Abrir `index.html` en un navegador moderno.
4. Iniciar sesión con las credenciales de demostración que aparecen en el README del proyecto.
5. Revisar panel, gráficas, reportes, exportación y formularios. Las bibliotecas cargadas por CDN requieren Internet.

## Antes de entregar
- Pegar el enlace real de GitHub en la plataforma de entrega.
- Pegar el enlace real del video.
- Asegurarse de que el video dure 15 minutos o menos y que los permisos permitan verlo.
